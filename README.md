# SCG Supply Chain Analytics

## Project Overview

Southern Cross Components Group (SCG) is a fictional manufacturing and distribution business created for a supply chain analytics portfolio project.

This project demonstrates how data analytics can support supply chain operations and decision-making, particularly in material planning, inventory management, procurement, production readiness, and demand forecasting.

Using synthetic operational data, the project aims to transform raw supply chain data into actionable business insights and practical recommendations.

The project is designed to demonstrate technical and analytical capabilities relevant to Supply Chain Analyst, Material Planner, Inventory Analyst, and related roles.

## Business Objectives

- Improve material availability and production readiness.
- Identify inventory risks, excess stock, and potential shortages.
- Evaluate supplier and procurement performance.
- Develop data-driven material planning and replenishment recommendations.
- Improve inventory visibility across supply chain operations.
- Support operational decisions through analytical reporting and dashboards.

## Project Scope

The project covers the following analytical areas:

1. **Material Planning & MRP** — Material requirements, netting, replenishment, and shortage identification.
2. **Inventory Management** — Stock levels, inventory movements, stock accuracy, and inventory risk.
3. **Procurement Analytics** — Purchase order performance, supplier lead times, and purchasing trends.
4. **Production Readiness** — Material availability and production plan versus actual analysis.
5. **Demand Analytics** — Demand patterns and forecasting.
6. **Supply Chain Performance** — Operational KPIs and management dashboards.

## Dataset

The project uses synthetic supply chain data consisting of 17 CSV files across three categories:

- Master data
- Transaction data
- Planning data

The dataset represents fictional manufacturing and distribution operations and contains no confidential information from real companies.

## Technology Stack

- Python — Data ingestion, automation, and data processing.
- PostgreSQL — Relational database and analytical SQL queries.
- SQL — Data transformation and supply chain analysis.
- Microsoft Power BI — Interactive dashboards and visualisation.
- Git & GitHub — Version control and project documentation.

## Project Architecture

CSV Source Data → Python ETL → PostgreSQL Raw Layer → Data Quality Assessment → Curated SQL Layer → Supply Chain Analytics → Power BI Dashboard
